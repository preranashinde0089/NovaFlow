# NovaFlow — Modern SaaS Landing Page

A modern, responsive, high-converting digital product/SaaS landing page built using pure **HTML5**, **CSS3**, and **vanilla JavaScript**.

## ✨ Features

- **Clean, Modern SaaS Aesthetic**: Inspired by modern startup design systems (Linear, Vercel, Stripe).
- **Light & Dark Theme Toggle**: Instant transition with persistent state saved in `localStorage`.
- **Zero Frameworks or Dependencies**: Pure HTML, CSS, and JS. No Tailwind, React, Bootstrap, or build tools required.
- **10 Complete Landing Page Sections**:
  1. **Sticky Navbar**: With brand mark, desktop navigation, theme toggle, CTA button, and responsive mobile hamburger menu.
  2. **Hero Section**: Eyebrow badge, bold typography, gradient accent text, dual CTA buttons, trust metrics, and an interactive **CSS SaaS Dashboard mockup**.
  3. **Trusted By**: Minimalist monochrome logos of fast-growing tech companies.
  4. **Features Grid**: 6 cards with custom gradient icon containers, descriptions, and hover elevation.
  5. **How It Works**: 3-step visual onboarding breakdown with illustrated previews.
  6. **Responsive Pricing**: 3 plans (Starter, Professional featured as "Most Popular", and Business) with a **Monthly / Annual billing toggle (20% discount)**.
  7. **Customer Testimonials**: 3 cards with 5-star ratings, realistic feedback, and gradient user avatars.
  8. **Exclusive FAQ Accordion**: Smooth expansion with vanilla JavaScript auto-collapsing other questions.
  9. **High-Impact CTA & Contact Form**: Full banner CTA plus a clean contact form featuring client-side input validation and toast notification.
  10. **Comprehensive Footer**: Brand mission, 4 categorized link columns, operational status indicator, and social media links.
- **Scroll Animations**: Smooth scroll-reveal triggered by the native `IntersectionObserver` API.
- **100% Offline Ready**: Embedded inline SVGs for zero broken icons or asset failures.

## 🚀 How to Run

You can view the project in two simple ways:

### Option 1: Direct File Opening (No Server Needed)
Simply double-click `index.html` in your file explorer, or right-click and choose **Open with > Chrome / Edge / Firefox / Safari**.

### Option 2: Live Server in VS Code
1. Open this folder (`saas-landing-page`) in Visual Studio Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and choose **Open with Live Server**.
